# MikuTV Japanese Language Pack (`日本語`)

Official declarative Japanese (`ja`) localization plugin for [MikuTV](https://github.com/yuchanns/MikuTV).

## Installation

1. Open **Settings → Appearance & Motion → Language** on Apple TV.
2. Select **Discover More Languages**, or install directly via **Settings → Plugins → Install from Repo** with `yuchanns/mikutv-locale-ja`.
3. Select **日本語** (or keep **Follow System** when tvOS is set to Japanese).

## Plugin Details

- **Kind**: `locale` (pure declarative JSON, zero JavaScript runtime, zero network permissions)
- **Language Tag**: `ja`
- **License**: Apache-2.0
